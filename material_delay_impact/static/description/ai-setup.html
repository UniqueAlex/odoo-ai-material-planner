Connect your AI account, step by step

AI Material Planner 19.0.1.1.1 · Configuration guide reviewed 27 October 2026.

AI is optional. You can calculate shortages and compare allocations without a key. To use AI, choose one provider, choose its model and save that provider's API key. You do not need four accounts or a key for every employee.

1. Choose the matching provider and API key

Ask an Odoo system administrator to configure the current company. Use an API account with available quota and permission to use the chosen model. A chat website login, password or chat subscription is not an API key or proof of API credit.

Presets are starting configurations, not a guarantee of model availability. Provider model names, account permissions and regional availability can change. If a preset is unavailable, confirm the exact model ID in that provider's account; a manually entered model remains unverified until checked.

Supported connection scope: direct official APIs only. Azure OpenAI, Vertex AI, Amazon Bedrock, local models and custom/OpenAI-compatible gateway URLs are not included. There is no custom Base URL field. Selecting OpenAI does not make another vendor's key work.

2. Open the configuration in Odoo

  1. Sign in as an Odoo system administrator and select the company whose configuration you want to set. Settings are scoped to the database and company.
  2. Open a confirmed purchase order with an unreceived storable material, then Material impact. Open this analysis page rather than an assigned shared-plan view.
  3. Click Set up AI on the first-use card, or AI settings at the top. If you only see an administrator reminder or cannot edit fields, ask your administrator to perform these steps.
  4. Select Provider and its suggested Model. Paste only the API key into API key, then click Save configuration. No server URL or programming is required for this configuration.
  5. The expected state is Saved, not yet tested. The key input clears after saving; this does not mean the encrypted saved key was lost. Use the saved status to check. Switching provider requires that provider's key.

3. Check the connection, then analysis capability

  1. Read the page's data disclosure and enable its AI data-sharing checkbox below settings. Saving a key alone does not enable AI actions.
  2. Click Test connection (may incur charges). Success means the selected key/model can answer a small request; it does not yet verify the analysis workflow.
  3. Click Verify analysis capability. This makes at most two small requests with synthetic data to check tool reading and structured output. It does not require business records.
  4. After capability verification passes, run one small material scenario and click Run AI analysis (may incur charges). Compare the result with the local facts, especially harmed orders and dates. Verification does not guarantee every AI statement is correct.

Connection and capability checks call the real provider when the customer clicks them and may consume API credit. The simulation-only status above describes our release tests, not what these customer-facing buttons do. Changing and saving settings clears previous verification. Save pending changes before testing. Avoid repeatedly clicking after a timeout: an interrupted request may already have incurred provider usage.

4. If setup does not work

Test buttons are disabledSave the configuration first, including any pending changes. Wait for an active operation to finish. Only an administrator can run configuration tests.

Insufficient credit or rate limitCheck API billing/quota for the key's project. For a rate limit, wait before retrying or adjust the provider's permitted quota. Chat membership alone does not establish API quota.
Connection passes but capability failsThe key works, but the selected model did not pass tool/structured-output checks. Check model support and permissions. Do not treat this as successful business analysis.
Network error or timeoutAsk the server administrator to check outbound HTTPS, DNS, TLS/proxy settings and supported region from the Odoo server. A browser reaching the provider's website is not sufficient.
Usage unavailable/incompleteThis means usage is unknown, not zero. The provider's account/billing records determine actual charges.

If AI setup fails, local material calculation and option comparison remain available. Contact aa7266901@gmail.com with the module version, provider, model ID and sanitized error. Do not send the API key or a production database.

Where the key and data go

The key is stored encrypted in the Odoo service's private data directory, scoped to the database and company. Business AI requests go from the Odoo server directly to the selected provider. Review AI data and fees before enabling business-data sharing. See installation and backup guidance for moving the server or restoring credentials. Remove key deletes this module's saved configuration; revoke a key separately in the provider console if needed.

中文速查：第一次怎么配置

  1. 只需选一个服务商，不必四个平台都开通；本地缺料计算和方案比较不需要 Key。
  2. 由 Odoo 系统管理员切换到对应公司，从采购单打开“物料影响”，点击“开始配置 AI”或“AI 设置”。共享方案页面不是配置入口。
  3. 选择服务商及建议模型，填该平台的 API Key，点击“保存配置”。保存后输入框清空是正常行为；看“已保存，尚未验证”状态。
  4. 阅读并勾选数据授权，依次点击“测试连接”和“验证分析能力”。这两个按钮会真实调用模型，可能产生 API 费用。
  5. 通过后先做一个小场景，核对 AI 解读与计算结果。改动配置并保存后需重新验证。普通用户请联系管理员配置，不必各自填写 Key。
  6. OpenAI、Gemini、Claude 已做接口模拟测试，尚未完成真实调用验收；DeepSeek 有此前真实验收记录。不能据此承诺所有模型、地区和账号均可用。
  7. 仅支持表中官方 API；不支持 Azure、Vertex AI、Bedrock、自建模型或第三方中转地址。聊天会员不等于 API 额度。
