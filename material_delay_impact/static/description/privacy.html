AI fees and data disclosure

Applies to AI Material Planner 19.0.1.0.0. Contact: aa7266901@gmail.com.

Free module; separate model account

The module price is zero. Local material calculations and deterministic option comparison do not call an AI provider. Optional AI requires the customer's own account and API key. The provider bills that account under its current plan; no model credits are included. One analysis may contain drafting, tool exchanges and bounded checks, so one button click can mean several API requests. A connection test can also incur a small charge. There is no subscription or vendor activation key imposed by this module.

What leaves Odoo

OperationRecipient / content

Excluded by the application's selected payload: purchase prices, contacts, free-form business notes and the entire database. Material names and document references may still be confidential. Requests go directly from your Odoo server to the configured provider endpoint, not through a vendor-operated proxy. Providers currently offered: DeepSeek (api.deepseek.com) and OpenAI (api.openai.com). The API key is sent only as authentication to the selected provider.

Your choice

Saving a key does not authorize every future transfer. The analysis page explains the fields above and asks you to enable AI actions for that page. Without permission, calculations remain local. Allowing AI then clicking an analysis/recommendation/test action sends the relevant request. Clearing permission affects new actions and cannot recall a request already sent. The interface does not grant an external provider general access to your Odoo database.

Storage and retention

Keys are encrypted in the Odoo service data directory, not Odoo business fields or browser storage. Review activities, shared plan snapshots and feedback are stored in your Odoo database; ordinary Odoo backups may include them. AI evidence snapshots and request results are stored temporarily in a private database table, so they can appear in database backups. Unused evidence expires after about 10 minutes; request results are retained for about 24 hours, with physical cleanup on later access or scheduled Odoo cleanup. Snapshots are cleared when execution completes. Browser navigation state may also retain report data. No API key is stored in the task table. The module adds no vendor analytics or telemetry endpoint. Your server's normal access/audit logs and provider logs remain subject to their own settings.

The provider controls its own processing location, retention and account terms. This module cannot promise zero retention or a particular jurisdiction; the customer must assess the selected provider and account settings before sending business data. See the provider's current policies and your organization's rules.

Duplicate requests and interruptions

Within retention, the same request and access scope reuse a stored result. An explicit new recommendation action starts a new potentially billable request. Interrupted requests are not automatically resubmitted; the provider may already have billed the interrupted request. A restored database can include prior results. Whole data-directory backups contain encrypted settings and the protected decryption material and must be handled as secrets.

Removal and support

Remove saved AI configuration in settings to stop using it, and revoke the key with the provider when necessary. Delete/export retained review records under your own Odoo retention policy. Do not email credentials or production database dumps to support. Send the module version, Odoo version/edition, OS, a sanitized error and reproduction steps with synthetic data. Screenshots must have confidential fields removed.
